**CyberSafe – Password Security Checker**

CyberSafe is a menu-driven password security checker developed using the C programming language. The main purpose of this project is to create awareness about password safety and help users understand the importance of strong passwords.

The application analyzes passwords based on their length and the presence of uppercase letters, lowercase letters, digits, and special characters. After analyzing these factors, it assigns a strength level (Weak, Medium, or Strong) and provides useful suggestions to improve password quality.

The project includes features such as password strength analysis, character checking, improvement recommendations, and an interactive menu. It demonstrates the practical implementation of C programming concepts, including functions, strings, loops, conditional statements, and character-handling functions.

**Objective:** To encourage better password practices and promote basic cybersecurity awareness through a simple and user-friendly application.

**Technology Used:** C Programming Language.
